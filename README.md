# The Birthday Archive — Photo Monograph & Memory Keepsake

A refined, humanized digital photo monograph and archive designed to document birthday portrait sessions, candids, and celebrations with authentic editorial typography, tactile warm linen aesthetics, and seamless photo management.

---

## ✨ Features

- **Personal Editorial Identity**:
  - Direct inline editing for the monograph title, milestone, personal memoir note, date, location, and photographer credit.
  - Cover portrait with instant replacement support.
  - Changes persist smoothly in local storage.

- **Human-Crafted Photographic Presentation**:
  - Warm archival linen canvas palette (`#fbf9f5`) paired with deep espresso typography (`#1c1917`) and tactile physical depth.
  - Zero cartoonish glows, no fake canvas sparkle particles, and no synthetic audio beeps.
  - Curated typography featuring Cormorant Garamond display serifs paired with Plus Jakarta Sans body.
  - Flowing Masonry editorial mode or uniform Contact Sheet Grid mode.

- **Curated Filtering & Organization**:
  - Editorial scene filters: *All Moments*, *Favorites*, *Portraits*, *Cake & Candles*, *Golden Hour*, *Outfits & Details*, *Candids & Friends*.
  - Real-time instant search bar for captions, notes, and scenes.
  - Flexible sorting: *Newest first*, *Oldest first*, *Favorites first*, *Alphabetical*.

- **Session Upload & Management**:
  - Drag-and-drop dropzone or device file picker with multi-file support.
  - Direct image URL import.
  - Custom memory fields: Title / Scene, Category, Date Taken, Favorite Highlight, and Story / Caption.
  - In-browser image compression to maximize fast local storage.

- **Darkroom Exhibition Lightbox & Slideshow**:
  - Distraction-free, immersive full-screen view centered purely on the photograph.
  - Full keyboard navigation: `Left` / `Right` arrows, `Escape` to close, `Spacebar` to toggle slideshow.
  - High-res photo download and quick metadata editing directly within the lightbox.

- **Archival Export & Print Keepsake**:
  - Export session data as a clean JSON backup.
  - Print / Save as PDF memory book with a dedicated print stylesheet that formats photos like a printed art book.
